AutoWifi · 校园网自动登录
连上校园 WiFi 后自动完成网页认证，支持接口表单提交与后台 WebView 静默登录两种方式， 并对国内常见校园网关产品族做了自动识别与适配。

仅供本人账号在合规前提下使用，请遵守所在学校的网络管理规定。

功能
启动自检页：纯代码绘制，五步体检（日志/配置/布局解析/加密/权限）逐条展示 ✓ 耗时ms 或 ✗ 异常链，任何一步失败都不闪退
连上指定 SSID 后自动触发登录；后台前台服务轮询 
+ 网络回调双触发
两种登录方式：

接口表单提交：简单门户直接 POST/GET 表单，可配置字段名、隐藏字段、成功关键词

网页静默登录：后台不可见 WebView 打开认证页，注入脚本自动勾选协议、填写账号密码、点击登录；带加密签名/摘要的门户由页面自身 JS 完成计算

主流产品族识别：GiWiFi/GPortal、锐捷 SRun、深澜 SDR、华为 ePortal/HGPortal、H3C iMC、Dr.COM/城市热点 Web 门户、通用 Web 表单
登录后延迟校验（默认 6 秒可调）+ 失败自动重试，避免门户放行延迟导致误判

内置浏览器抓包：Hook fetch/XHR、监听表单提交，识别登录请求并回填配置

一键诊断：外网探测、认证页解析、配置摘要、真实登录请求与响应、二次探测、结论建议

完整运行日志（可导出/分享到「下载/AutoWifi」），主界面常驻实时输出栏
密码使用 AndroidKeyStore AES-GCM 加密后存入本机 SharedPreferences，不明文落盘
配置导入/导出（剪贴板 JSON）、登录历史、开机自启、电池优化白名单引导、系统网络建议自动连接
可更换背景：内置渐变或从相册选图

主界面安全模式：布局意外解析失败时进入纯代码兜底页，展示逐层异常链

适配范围与边界
仅适用 Web 页面认证型门户；不支持、也无法在普通应用内复刻：
专用客户端私有协议（锐捷/深澜/Dr.COM 私有端口登录）
802.1X 企业认证
短信 / 图形 / 滑块验证码（需人工一次）
Android 系统限制：应用不能静默切换 WiFi，只能通过系统网络建议让用户确认后自动连接。
产品族识别基于 URL 与页面特征，学校后台改版后可能需要补充规则；动态渲染页面优先走网页静默登录。
